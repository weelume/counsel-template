# 验证说明

本地 WSL Linux 文件系统完成 pnpm typecheck、lint、test（3 项路由回归）、build。生产服务 24 条中英文路由均返回 HTTP 200 且包含 h1；服务测试后停止。具体命令时间与源码摘要见 reports/verification.json。

内置浏览器实测 1440×1000、834×1180、390×844，另补测 320px 全部英文页面。首页、服务项目、文章、联系每端四张截图位于 assets，按实际解码像素登记，桌面 1430×993、平板 824×1166、手机 380×822。截图由可见页面采集，未放大。正常滚动条占宽 10px。

申请表单填写演示数据后显示仅本地校验成功，控制台只输出校验状态。菜单展开锁定背景，Escape 关闭恢复焦点。没有真实发送、保存或后端。

参考页面：首页、关于、工作内容、服务、文章列表/四篇详情、申请、联系、隐私均已通过内置浏览器读取。观察到原站文字拆分、轮播持续位移、照片最终旋转及手机菜单展开。未观察到视频、FAQ 或可拖拽回弹控件，不额外虚构这些功能。

本地采样确认文字从 opacity=0/translateY 到 opacity=1/none；循环轨道不同时刻持续位移、两行方向相反，聚焦 paused、移开 running。尊重 prefers-reduced-motion：入场直接显示，循环停止，菜单瞬时切换。

## 有意调整与边界

按制作要求改用 MiSans/Poppins、限制标题字号、默认中文、玻璃卡片与定制原生滚动条；不复制参考站装饰箭头。隐私说明按无后端演示真实改写。原站未提供设计工程，动画参数依据浏览器观察重建，不声称逐帧/逐像素一致。鼠标设备模拟不等同于实体 iPad/iPhone 的触控惯性测试。系统覆盖式滚动条差异保留原生行为。
